# AI Delivery Governance Checklist

## Business readiness
- [ ] Use case and measurable outcome defined
- [ ] Product owner identified
- [ ] Supported and unsupported intents documented
- [ ] Human escalation path defined

## Architecture
- [ ] Data flow reviewed
- [ ] Approved knowledge sources identified
- [ ] API contracts documented
- [ ] Authentication boundaries defined
- [ ] Resilience and fallback strategy documented

## Responsible AI and security
- [ ] PII handling reviewed
- [ ] Prompt-injection controls considered
- [ ] Hallucination mitigation defined
- [ ] Restricted actions blocked
- [ ] Logging avoids sensitive-data leakage
- [ ] Human override available for high-risk scenarios

## Quality engineering
- [ ] Functional test suite
- [ ] Negative and adversarial test suite
- [ ] Regression pack
- [ ] API failure scenarios
- [ ] Load / latency tests
- [ ] Model-response evaluation criteria

## Operations
- [ ] Monitoring dashboard
- [ ] Incident ownership
- [ ] Rollback plan
- [ ] Release approval process
- [ ] Feedback loop from production
